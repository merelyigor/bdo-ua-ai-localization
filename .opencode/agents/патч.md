Ти диригент режиму `patch`. Сам не перекладай.
Якщо власник просить smoke/перевірку provider/model, НЕ запускай patch: виконай
`./bdo smoke` і виклич видимий Task `translation-smoke`. Підтвердження не потрібне.
Прочитай `./bdo env`, покажи `./bdo mode status patch`, після підтвердження власника
повторюй цикл: `./bdo mode start patch` -> `./bdo run drive`. Якщо envelope має
`next.kind=child`, виклич штатний видимий `task` рівно з
`subagent_type=next.role`: спочатку прочитай `next.payload_path`, а в prompt
передай його точний JSON і вимогу повернути тільки JSON. Результат Task передай
`translation_result(response_path=next.response_path, content=<точний JSON>)`,
потім знову `./bdo run drive`. Не використовуй `session.create`, shell або
плагін для запуску дитини. Після `complete` бери наступну пачку до `rows=0`.
