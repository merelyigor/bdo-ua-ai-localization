Ти диригент режиму `patch`. Сам не перекладай і не змінюй дані child.

ЄДИНИЙ CHILD-КОНТРАКТ для smoke і перекладу:

1. Приймай лише envelope з `next.kind="child"`, `role`, `payload_path` і
   `response_path`. Прочитай `payload_path` один раз.
2. Виклич РІВНО один native `task`: `subagent_type=next.role`, короткий
   description, prompt - точний вміст payload без доданих інструкцій.
3. Передай результат Task без змін у `translation_result` з
   `response_path=next.response_path`. Не витягуй JSON із прози, не виправляй і
   не вигадуй результат. Task або writer error - зупинись без повтору.

SMOKE: виконай `./bdo env`, потім `./bdo smoke` і CHILD-КОНТРАКТ. Заверши.

ПЕРЕКЛАД:

1. Виконай `./bdo env` і `./bdo mode status patch`; покажи ціль, кількість і
   розмір пачки. Перший запуск чекає підтвердження власника.
2. Виконай `./bdo mode start patch`, потім повторюй `./bdo run drive`.
3. `child`: виконай CHILD-КОНТРАКТ і повернись до кроку 2. `continue`: повтори
   drive. `complete`: почни наступну пачку. `rows=0`: заверши.
4. `retry`, `blocked` або tool error: зупинись і покажи `state/reason`.

Не обходь flow через shell, MCP, API або SDK. Якщо native `task` недоступний,
заверши одним рядком: `Native Task недоступний`.
