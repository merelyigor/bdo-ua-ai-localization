# bdo-ua-ai-localization: контракт для AI-агента

Цей репозиторій · набір скриптів і промптів, який перекладає рядки Black Desert
Online українською через локальні моделі й пише результат у BDO UA Translate
Agent API. Тут немає веб-застосунку, БД і фронтенду: усе, що відбувається, це
HTTP до API, виклики Ollama і файли робочого стану.

## 1. Пріоритет і стоп-умови

1. Вказівка власника в поточній задачі має пріоритет, крім безпекових заборон.
2. Не вигадуй файл, прапорець, поле API чи результат перевірки. Спочатку факт:
   `rg`, читання скрипта, реальний вивід команди.
3. Після двох однакових невдалих спроб зупинись, назви причину, зміни підхід.
4. Зупинись і запитай, якщо ціль неоднозначна або дія необоротна.
5. Не розширюй задачу рефакторингом чи новою залежністю без потреби.

## 2. Незмінні заборони

Повний перелік · [`.opencode/critical-rules.md`](.opencode/critical-rules.md).
Коротко: `git commit`/`push` лише з дозволом; ключі з `.env` не виводити нікуди;
`--env prod` лише з дозволом на конкретний прогін; ручні переклади, ревізії й
рішення модераторів не перезаписувати; identity рядка не змінювати; MLX-моделі
не використовувати.

## 3. Обовʼязковий цикл роботи

1. `./paths.sh` · переконатись, що розкладка вирішується.
2. Сформулюй ОДНУ ціль і критерій готовності.
3. Знайди реалізацію й усі call sites (`rg`). Поведінку не вгадуй: скрипти
   рясно комментовані саме тому, що причина рішення важливіша за код.
4. Зроби найменшу цілісну зміну.
5. Прогони перевірки з розділу 5.
6. Переглянь власний diff на секрети, `output/`, `state*/` і зміни поза задачею.

## 4. Що де лежить

| Що | Де |
|---|---|
| Промпти субагентів | `.opencode/agents/translation-*.md` |

## 5. Перевірки

```bash
./paths.sh                                  # розкладка на диску
bash -n <script.sh>                         # синтаксис
shellcheck -x -S warning *.sh               # статичний аналіз
bash .opencode/validate-translation-agents.sh  # конфіг і frontmatter агентів
./sync-opencode-models.sh                   # провайдер OpenCode знає моделі
./check-runtime.sh                          # локальна модель тримає контракт
./test-api.sh                               # read-only звʼязок з API
```

Ніколи не повідомляй «перевірки пройшли», якщо команда не завершилась з кодом 0.
Якщо перевірку неможливо запустити · назви точну причину, що саме не перевірено
і який це ризик.

## 6. Стиль

- Відповідь власнику · українською.
- Коментарі в коді пояснюють ЧОМУ, а не ЩО. Наявні коментарі-обґрунтування не
  видаляти: якщо причина змінилась, перепиши коментар.
- У видимому користувачу тексті не використовувати тире «—», лише `·` або дефіс.
- `BDO` означає Black Desert Online, а не цей репозиторій.

## 7. Обслуговуваний проєкт

`TRANSLATE_PROJECT_ROOT` у `.env` вказує на чекаут проєкту BDO UA Translate.
Він потрібен лише для читання його документації й для `run-in-docker.sh`. Сам
переклад іде через HTTP до API і без цього шляху. Той проєкт має власні правила:
нічого в ньому не змінювати з цього репозиторію.
