# Передача зміни до серверного Agent API

Цей toolkit не змінює серверний проєкт. Якщо під час роботи встановлено, що
чинного Agent API недостатньо, агент зупиняє обхідні спроби через Docker, БД,
Artisan або серверний filesystem і дає власнику окремий copy-ready промпт.

## Обовʼязковий формат

```text
Працюй у серверному проєкті BDO UA Translate API.

Мета: <одне конкретне серверне доопрацювання>.
Підтверджений дефект/прогалина: <фактична відповідь API, код помилки або
відсутня можливість; без секретів і локальних шляхів>.
Потрібний контракт: <endpoint, method, request, response, status/error codes>.
Сумісність: не ламай чинних клієнтів; явно опиши additive або breaking change.
Безпека: збережи auth, abilities, rate limits, validation та audit trail.
Перевірки: додай серверні regression-тести для success, validation, auth і
ідемпотентності/повтору, якщо endpoint мутуючий.
Документація: онови канонічний серверний API contract.
Результат для клієнтського агента: поверни точний контракт і приклад JSON без
секретів; не змінюй bdo-ua-ai-localization із серверної сесії.
```

Промпт має описувати лише доведений API gap. Не переносити в нього дампи БД,
ключі, приватні URL, абсолютні локальні шляхи чи припущення про реалізацію.
