# Довідник команд `bdo`

> Цей файл згенеровано з [`cli/command-registry.json`](../cli/command-registry.json).
> Не редагуйте його вручну: після зміни реєстру виконайте `php scripts/generate-command-docs.php`.

## ПРОГІН І СЕРЕДОВИЩЕ

| Команда | Призначення |
| --- | --- |
| `./bdo loop` | драйвер: провести пачки до кінця цілі без втручання |
| `./bdo tui` | вікно-монітор у терміналі: стан, журнал, прогін без браузера (те саме, що ./bdo без аргументів) |
| `./bdo watch loop&#124;tui [--batches N&#124;--once]` | запустити прогін або вікно в tmux-сесії, яку власник бачить живими очима (--show, --stop) |
| `./bdo gif [--tape&#124;--out FILE.gif]` | записати екрани TUI у GIF для документації через vhs |
| `./bdo timer [start&#124;status&#124;check]` | скільки триває поточна робоча сесія і скільки лишилось до 4-годинної межі |
| `./bdo session [new&#124;close&#124;list&#124;show]` | сесія роботи: історія пачок, підсумок і прибирання журналів за BDO_KEEP_DAYS |
| `./bdo web [--background&#124;--status&#124;--stop&#124;--no-open]` | ОСНОВНИЙ інтерфейс: сторінка в браузері · вільний порт, посилання в терміналі |
| `./bdo env` | яка ціль стоїть у .env (PROD або DEV) |
| `./bdo sync` | показати зміни .env як «було → стало» з маскуванням ключів і зберегти знімок |
| `./bdo runtime` | capability gate активної моделі перед першою пачкою |
| `./bdo platform` | macOS, Linux або Windows/WSL2 preflight |
| `./bdo run start&#124;show&#124;end&#124;drive` | зафіксувати / показати / зняти ціль; JSON-крок рушія |
| `./bdo patches [N&#124;all] [machine&#124;manual&#124;both] [--full]` | де ще є робота за патчами |
| `./bdo mode status&#124;start <mode> [N] [patch] [категорія]` | preset або наступна пачка; категорія звужує вибірку |
| `./bdo gate [профіль]` | quality gate: preflight docs shell agents runtime api full |

## ВИБІРКА Й ПАЧКА

| Команда | Призначення |
| --- | --- |
| `./bdo patch` | стан патча: скільки лишилось |
| `./bdo fetch` | взяти одну пачку рядків з API |
| `./bdo batch new&#124;dir&#124;check&#124;end` | тека пачки, її шлях, належність файлів, закриття |
| `./bdo subset` | підмножина рядків за identity (для repair) |
| `./bdo show` | показати рядки людині |
| `./bdo context` | підтверджені приклади для одного рядка |

## ПІДГОТОВКА ПАЧКИ

| Команда | Призначення |
| --- | --- |
| `./bdo memory find&#124;apply&#124;expand` | памʼять перекладів: пошук, застосування, збірка |
| `./bdo glossary gaps&#124;resolve` | прогалини глосарію (ВИРОК) і запит терміна |
| `./bdo schema build&#124;qa&#124;clear&#124;show` | staged-схема constrained decoding |
| `./bdo payload worker&#124;qa&#124;terminology&#124;judge` | компактний payload для ролі |

## ПЕРЕВІРКА Й ЛІКУВАННЯ

| Команда | Призначення |
| --- | --- |
| `./bdo normalize` | детерміновані виправлення (латинські гомогліфи) |
| `./bdo items` | гейт identity: збірка items із перевіркою source_hash |
| `./bdo russianisms` | словниковий детектор русизмів |
| `./bdo suspects [--list]` | звіт про підозрілі записи глосарію (глосарій не змінює) |
| `./bdo validate` | валідація на боці API |
| `./bdo heal` | сходинки лікування й payload для repair |
| `./bdo qa-fixes` | фільтр виправлень від QA |
| `./bdo merge` | накласти виправлення на кандидата |

## ЗАВЕРШЕННЯ

| Команда | Призначення |
| --- | --- |
| `./bdo commit` | PASS у шар, решта в модерацію, збої в карантин |
| `./bdo write` | прямий запис у вибраний канал |
| `./bdo moderation` | черга модерації: список, approve, reject |

## ОБСЛУГОВУВАННЯ

| Команда | Призначення |
| --- | --- |
| `./bdo audit` | що робили моделі цього прогону за власним журналом викликів · **для розробки**, у флоу перекладу не викликається |
| `./bdo models-run` | що робили моделі цього прогону (власний журнал) |
| `./bdo inspect [тека]` | інспекції PhpStorm по проєкту; працює лише при закритій IDE · **для розробки**, у флоу перекладу не викликається |
| `./bdo review` | стан проєкту одним екраном: плани, дефекти, черга, останні пачки · **для розробки**, у флоу перекладу не викликається |
| `./bdo incidents [--list N]` | виклики моделі, що завершились не вердиктом ok, за журналом прогону |
| `./bdo quarantine [--list&#124;--clear]` | рядки, які не доїхали в жоден шар |
| `./bdo judge` | вироки судді: розподіл, виродження, калібрування |
| `./bdo terms describe` | завдання для ролі: описати найчастіші терміни без опису |
| `./bdo terms submit` | надіслати описи як пропозиції; перед записом звіряє свіжий стан терміна |
| `./bdo terms [N]` | терміни глосарія без опису, за частотою в перекладених пачках |
| `./bdo concepts` | оновити кеш понять гри з глосарія (один запит на прогін) |
| `./bdo clean` | прибрати недосяжні теки пачок і старі дампи output |
| `./bdo paths` | що куди вирішилось із розкладкою |
| `./bdo api` | read-only smoke Agent API |
