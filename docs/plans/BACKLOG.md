# Черга робіт

Єдине місце для всього залишку роботи: великі теми посилаються на окремі плани,
дрібні задачі можуть жити без окремого файла.

- **Статуси:** `готово` · `в роботі` · `чекає` · `відкладено` · `перевірити`.
- Рядок має бути самодостатнім для нової сесії: ціль, шлях до плану й блокер.
- Статус оновлюється разом із кодом або документацією, які його доводять.

## Як користуватися

1. Нову велику тему додати в `backlog/` і зареєструвати в `README.md`.
2. Почату тему перевести в `active/`.
3. Не видаляти залишок мовчки: позначити `відкладено` з причиною або передати в
   інший план.
4. Закрити задачу лише разом із доказом перевірки.
