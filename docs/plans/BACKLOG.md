# Черга робіт

Єдине місце для незавершених рішень і вимірів. Завершені або відхилені пункти
не маскуються під backlog: результат живе в коді, тесті або git-історії.

Статуси: `в роботі` · `чекає` · `відкладено` · `перевірити` · `відхилено`.
Кожен рядок має ціль, блокер і посилання на живий документ.
