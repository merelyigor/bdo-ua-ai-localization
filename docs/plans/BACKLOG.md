# Черга відкладеного

Кожен рядок має ціль, причину відкладення і ознаку готовності. Завершене й
відхилене тут не маскується під backlog.

Статуси: `чекає` · `відкладено` · `перевірити` · `відхилено`.

| Статус | Задача | Причина / готовність |
|---|---|---|
| `відкладено` | Пропозиції глосарія (`POST /glossary/proposals`) і роль `translation-glossary`. | Терміни в проді можуть бути неактуальні (власник, 2026-09-25). Готовність · власник каже, що терміни актуальні. |
| `відкладено` | Перекриття кроків між пачками (`max_parallel_batches > 1`). | Спочатку замір у P08; простій моделі 17.7 %, замір 2026-09-27. Паралелізм Ollama належить власнику. |
| `відкладено` | TUI, mac-app, Windows. | Не входять у v1 (LESSONS_FROM_PHP.md). Готовність · явний запит власника. |
| `відкладено` | Порятунок готових items з відповіді `truncated`. | v1 закриває пачку `failed_terminal` (D-17). Готовність · замір P08 показав, що `truncated` частий. |
| `відкладено` | Поняття гри (`GET /glossary/concepts`, `docs/API.md`) у payload worker. | Клієнт `api/endpoints.py` цей ендпоінт не вживає; у v1 лише глосарій, а терміни на паузі (власник, 2026-09-25). Готовність · власник вирішує, що поняття потрібні в payload. |
| `відкладено` | Калібрування судді рішеннями людини (`GET /translations/decisions`). | Ендпоінт на сервері ще не задеплоєний (docs/API.md). |
| `відкладено` | Правопис і граматика перекладу локальним LanguageTool (сервер на Java, близько 200 МБ). | Спершу замір: скільки зауважень на пачку 50 і яка частка хибних на назвах гри. Готовність · власник дозволив поставити Java-сервер. |
| `відкладено` | Перехід перевірки вжитку термінів з правила основ на морфологію `pymorphy3`. | Спершу вимір P11 крок 5.3 (розбіжності двох правил); терміни на паузі. Готовність · рішення власника після виміру. |
| `відкладено` | Підтвердити серверну ідемпотентність `POST /translations`: повтор з тим самим `Idempotency-Key` не створює нової ревізії. | Клієнт цього не бачить: немає ні ознаки повтору у відповіді, ні ендпоінта ревізій. Готовність · сервер документує поведінку повтору або віддає ознаку повтору. |
| `відкладено` | Причина або дефект для кожної пропозиції в `GET /translations/proposals`, показаний на `/review`. | Перевірена DEV-відповідь містить `status`, але не має reason/defect поля; UI не виводить причину з непрямих ознак. Готовність · API контракт повертає визначену машиночитану причину для кожної пропозиції. |
| `відкладено` | Колір джерела llama-swap у каталозі (`--runtime-omlx`/`--runtime-ollama` і `.catalog-runtime-dot.*` в `app.css` є лише для двох) і підзаголовок «Ollama та oMLX» на «Підключенні» (`setup.html`). | Знайдено виконавцем у P42 1.1; косметика, без неї llama-swap має типовий колір `var(--gold)`. Готовність · будь-який крок UI `/models` чи `/setup`. |
| `відкладено` | Позначка середовища на `/history`: історія завжди читається з API поточного середовища, навіть коли пачку проганяли на іншому (DEV-пачка при PROD покаже PROD-версії). | Помічено на звірці P57 1.3, 2026-10-01. Готовність · рішення власника, чи показувати підпис «історія з PROD» або попередження при розбіжності `session.env`. |
