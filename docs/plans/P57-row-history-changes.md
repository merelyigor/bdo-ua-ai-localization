## Що вже є

`/history?hash=<hash>` показує дві колонки, ШІ-шар і ручний шар. У кожній
колонці до 50 версій, найновіші зверху: текст, `vN`, автор, модель і дата.
Відкривається лише посиланням «історія» з `/review` або з вердикту `/run`.

## Goal

- На `/history` видно, ЩО змінилось між сусідніми версіями одного шару: вставлені й прибрані слова підсвічено.
- Історію можна відкрити не лише посиланням: є поле пошуку за хешем.
- Можна переглянути історію кількох рядків одразу: усі рядки пачки прогону зі змінами в ній, кожен з переходом до своєї історії.

## Definition of Done

- [ ] Кожна версія, крім найстарішої, має розгортуваний блок «що змінилось» зі словесним diff до попередньої версії того самого шару. Diff рахує стандартна `difflib`, без нової залежності. Кольори · лише `var(--…)`.
- [ ] `truncated` з API показано підписом «показано 50 останніх версій».
- [ ] Поле хешу на `/history`; хибний хеш · наявна відмова `invalid_hash`; невідомий · 404 з API показано причиною.
- [ ] Історія пачки: з `/sessions` і з `/run?batch=<id>` посилання «історія рядків пачки» веде на список рядків пачки (оригінал коротко, вердикт, посилання на `/history` рядка з `from`-поверненням на пачку).
- [ ] Звірка на DEV, лише читання, знімки `P57-*`; `uv run bdo gate` 0; план видалено на закритті (D-59).
