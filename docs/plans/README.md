## Активний план

Перший план зі статусом `approved` або `in-progress` у таблиці нижче. Плани
виконуються по порядку реєстру; закривши план, сесія переходить до наступного.

У реєстрі й теці лише активні плани (`draft`, `approved`, `in-progress`,
`blocked`). Закритий план видаляється тим самим комітом, що його закриває
(власник, 2026-09-30): підсумок лишається рядком у [`PROGRESS.md`](PROGRESS.md),
повний текст · в історії git (`git log --diff-filter=D -- docs/plans/`).
Номери не перевикористовуються. Наступний номер плану · **P56**.
