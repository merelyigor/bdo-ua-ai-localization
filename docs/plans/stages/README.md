# Етапи робіт

Один файл на етап. Етап · це послідовність підетапів, кожен із яких має
цілісну мету, обмежений набір файлів, критерії приймання й перевірку.

## Статуси підетапу

| Статус | Значення |
|---|---|
| `не починався` | узгоджений намір без коду |
| `у роботі` | код почався, критерії ще не виконані |
| `реалізовано` | код і тести є, gate зелений, рев'ю не проходило |
| `прийнято` | рев'ю винесло ACCEPTED |
| `відкладено` | свідоме рішення власника, з причиною |

Статус змінює той, хто має право: `реалізовано` ставить агент,
`прийнято` · тільки рев'ю (`docs/ai-workflow/REVIEW.md`).

## Правило синхронності

Коміт, який змінює поведінку, ТИМ САМИМ комітом оновлює статус підетапу. Без
цього план і код розходяться, і наступна сесія працює за застарілою картою.
