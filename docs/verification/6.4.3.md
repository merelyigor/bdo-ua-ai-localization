# Verification 6.4.3

## Process authoring boundary

Новий guard у `scripts/agent-check.sh` перевіряє механізм `АРХІТЕКТОРСЬКИЙ ПАТЧ`,
відсутність старого blanket-правила, авторство в process docs, норматив §17.5
і наявність patch-механіки в `PROMPTS.md` та `WORKFLOW.md`.

Дослівний sabotage diff:

```diff
--- /tmp/prompts-6.4.3-before-sabotage.md
+++ docs/ai-workflow/PROMPTS.md
@@ -45,8 +45,6 @@

 Додаткові блоки за потреби: `ПЕРЕНОС`, `ДУБЛЮВАННЯ ПРАВИЛА`, `БЕЗПЕКА`, `ДАНІ`.
-## Блок `АРХІТЕКТОРСЬКИЙ ПАТЧ`
-
 Process rules/plans авторить лише АРХІТЕКТОР: `AGENTS.md`, `.cursorrules`, `CLAUDE.md`, `QWEN.md`, `docs/AI_AGENT_RULES_REFERENCE.md`, `docs/ai-workflow/**`, `docs/plans/**`.
```

Команда:

```text

./bdo gate docs > /tmp/docs-6.4.3-sabotage-1.out 2>&1
```

```text

FAIL: PROMPTS.md не містить блок архітекторського патча
```

Після restore з `/tmp/prompts-6.4.3-before-sabotage.md` повторний `./bdo gate docs`
дав code 0 і `Agent gate passed: docs`.
