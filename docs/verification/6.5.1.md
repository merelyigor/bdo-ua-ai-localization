# Verification 6.5.1

## D129: timestamp proof

Перед нормалізацією `tests/cli-run-foundation-parity.sh` читає кожен
створений `run-started-at`, перевіряє decimal integer milliseconds і часовий
інтервал запуску з запасом 1500 ms, а лише потім записує `TIMESTAMP` у snapshot.
Self-test перевіряє `garbage`, незмінність `run-target`, manifest/state та
довільної error reason.

Sabotage diff:

```diff
-        $this->writeFile($stateDir.'/run-started-at', (string) (int) floor(microtime(true) * 1000)."\n");
+        $this->writeFile($stateDir.'/run-started-at', "garbage\n");
```

Command:

```text
/usr/bin/time -p bash tests/cli-run-foundation-parity.sh
```

Relevant output:

```text
FAIL: fresh-dev php: run-started-at не є integer milliseconds у часовому вікні
real 3.56
```

Exit code: `1`.

Restore: original `microtime(true) * 1000` expression restored exactly.
Green rerun: `bash tests/cli-run-foundation-parity.sh` → code `0`, `real 12.11`
before the final combined restore run; final rerun → code `0`, `real 11.76`.
