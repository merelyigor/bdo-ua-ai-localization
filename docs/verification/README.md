# Артефакти перевірки

АРХІТЕКТОР веде рев'ю з браузера й не може відтворити саботаж сам. Тому коміт,
який додає або змінює перевірки, кладе сюди файл `<версія>.md` із ДОСЛІВНИМИ
виводами. Це те, що рев'юер читає замість запуску.

Переказ не приймається. «Саботаж спрацював» без дифа й коду виходу є порожнім
рядком: рев'юер не може відрізнити його від невиконаної роботи.

## Форма файла

```text
# <версія> · <коміт>

## Саботаж 1 · <що ламаємо й яку властивість це перевіряє>
діф:      (unified diff, дослівно)
команда:  (як запущено)
вивід:    (дослівно, обрізаний до релевантного)
код:      (код виходу)
час:      (секунд)
відкат:   (підтвердження, що дерево чисте)

## Саботаж 2 · ...

## Серії
(команда, коди виходу через кому · для перевірок на нестабільність)
```

## Що сюди НЕ кладуть

Повний вивід гейта · його дає CI. Скріншоти. Міркування. Усе, що не є доказом
конкретного твердження з пакета завдання.

## Коли файла може не бути

Коміт без нових і змінених перевірок артефакту не потребує. У такому разі звіт
ВИКОНАВЦЯ каже про це прямо, а не мовчить.
