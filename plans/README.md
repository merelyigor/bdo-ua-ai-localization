# Плани: реєстр

Плани — за глобальним skill `dev-standard`. Автотестів у проєкті немає (D-08):
приймання кожного кроку · звірка у браузері штатним браузером Codex (D-65), тому
веб іде першим (D-34) і кожна фаза додає свій екран.

Блок реєстру нижче генерує `plan.py index` — не редагуй вручну. Інструменти
`plan.py` і `plan_check.py` живуть у глобальному skill `dev-standard`
(`scripts/` цього skill), а не в репозиторії: викликайте їх звідти.
Відкладені питання лежать у [`BACKLOG.md`](BACKLOG.md); розділ «Відкладене»
не дублюється тут — `plan_check` вимагає тримати його лише в `BACKLOG.md`.
