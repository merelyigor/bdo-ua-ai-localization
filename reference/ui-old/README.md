# reference/ui-old/ · як виглядає інтерфейс попередника

Знімки живого UI `$OLD` (`../bdo-ua-ai-localization`), зняті
2026-09-26 у MCP Playwright: ширина 1440, темна тема, живі дані PROD.
Це ЕТАЛОН вигляду для P09: новий екран має виглядати так само. Відмінність
допускається лише там, де її називає план P09.

Знімки · тільки картинки для порівняння. Розмітку й поведінку беріть із файлів
`$OLD`, названих у таблиці. Читати їх можна лише read-only; копіювати файли
заборонено (AGENTS.md п. 3а).

Знімки `*-full.png` охоплюють сторінку від шапки до низу. Знімки без
`-full` · вікно 1440×900 у читабельному масштабі або інший стан того самого
екрана.

Спільне для всіх знімків:
- **шапка**: логотип і «BDO · AI Localization / Українська локалізація. Разом.»;
  п'ять пунктів навігації з підсвіченим поточним; індикатор оновлення з
  кольоровою крапкою; чипи `temp`, `ctx`, `think`;
- заголовок екрана `h1` і поруч сірий підзаголовок одним рядком;
- панелі з заокругленими рамками на тлі `bdo-background.webp`.

У `07-models-full.png` значення полів ключів і адрес замасковані `••••` перед знімком.
Бічна вкладка «ліміти» є на всіх знімках; у P09 її додає крок 5.3.
